# 缩小红点、手机滑动和粘连识别更新

本次更新不增加依赖，不需要改宝塔反向代理或其他站点。

## 已部署用户更新

下载仓库最新 ZIP：https://github.com/ChazJing/rice_number/archive/refs/heads/main.zip

解压后用 Xftp 覆盖服务器 `/www/wwwroot/rice.chazjing.icu/app/` 内这四个文件，保持目录结构：

- `backend/detection.py`
- `frontend/index.html`
- `frontend/app.mjs`
- `frontend/style.css`

不要修改 `.env`。随后在 Xshell 执行：

```bash
systemctl restart rice-number.service
curl -fsS http://127.0.0.1:8000/api/health
```

健康检查返回 `"status":"ok"` 后，关闭微信内的网站页面，再重新打开。

## 使用变化

- 默认红点直径约 4 CSS 像素，原来约 9 像素。可选小、中、大；黄色复核外圈同步变小，导出图片使用所选大小。
- 点击范围比可见红点大，方便删除；密集区域先放大或切换“补点”。
- 手机上普通修正模式可在照片上上下滑动页面。查看放大照片的其他位置时，切换“移动”后拖动；之后切回“修正”。
- 照片和标记分层绘制，补删红点、切换点大小时不重新绘制照片。
- 同张照片有至少三粒大小相近的分离种子时，用它们估计粒径，辅助寻找并排粘连区域的轮廓峰。计数依据仍是可见形状和红点，不按总面积直接推算粒数。
- 黑色稻粒仍可依据局部明暗差被识别。颜色只是辅助信息。

这仍是传统图像分割算法，没有加入训练好的水稻 AI 模型。明显遮挡、轮廓消失或背景纹理相似时仍可能漏检或误检。新增模拟测试不能代表真实照片的准确率。

## 真实照片测试与更智能的方案

测试用原始 JPG 可放在本地的 `work/private-photos/`；`work/` 已被 Git 忽略，不上传公开仓库。人工标点导出的 JSON 可作为逐粒中心点参考，需复核后才能作为评估真值。应比较漏检、误检和修正次数，不能只看总数。

如果真实照片上修正量仍大，下一步是训练水稻专用的检测、实例分割或点定位模型。训练可在其他有 GPU 的环境完成；两核服务器只做轻量模型推理，具体速度需用真实照片测试。通用模型不会自动学会稻粒类别。

可参考稻穗点定位项目 [GrainCountingP2PNet](https://github.com/UTokyo-FieldPhenomics-Lab/GrainCountingP2PNet)。该项目研究稻穗场景，不能假定它的预训练模型适合白纸上散放的种子；引入代码或权重前还需确认其授权条件。本次更新没有引入该项目的代码或权重。
